# Style Handoff Guide · ART 3041

Here is the technical style handoff based on the design decisions for the class homepage. Follow these rules strictly whenever building or editing this page.

1. **Typography — Headings:** Set all headings in **Cormorant Garamond** (serif, designed by Christian Thalmann). Headings must be exceptionally large to establish high visual contrast: `h1` at `clamp(3rem, 8vw, 6rem)`, `h2` at `clamp(2rem, 5vw, 3.25rem)`, and `h3` at `clamp(1.5rem, 3vw, 2rem)`. Use a weight of 500–600, a tight line-height of 1.05–1.15, and a letter-spacing of `-0.01em`.
2. **Typography — Body:** Set all body text, labels, and list content in **Jost** (sans-serif, designed by Owen Earl). The base size is `1rem` (16px) with a line-height of `1.6`. Keep body text visually small and restrained relative to the large headings to honor the core typographic rule of the page.
3. **Color Palette:** The base palette is strictly limited to three colors. The background is cream-colored (`#F6EFE2`), all text and headings are brown (`#4A3222`), and the accent color is white (`#FFFFFF`). No additional colors may be introduced.
4. **Accent Usage:** Use the white accent (`#FFFFFF`) for link text, borders/dividers, and button fills. Additionally, use it for hover/active state fills, focus outlines on interactive elements, and thin section-divider rules between page blocks.
5. **Hero Image:** The hero image must run full-width across the absolute top of the page. It must have a minimum height of `80vh` on laptop screens and `60vh` on mobile phones. The image must fill the container edge-to-edge using `object-fit: cover`.
6. **Name Placement:** The student's name must sit inside the hero image itself, positioned at the bottom of the container. It must use the large Cormorant Garamond heading style and sit on top of a subtle, low-opacity dark gradient overlay at the base of the hero to ensure legibility over any background graphic.
7. **Layout — Columns:** This is a one-page index of links, so it must utilize a clean, single-column layout across all devices (one column on laptop, one column on phone). Content must be centered with a `max-width` of `720px` on desktop and full-width with `24px` side padding on mobile screens.
8. **Breakpoints:** Use a single responsive media query breakpoint at `768px` to cleanly manage the transitions between laptop and phone text scales or layout padding.
9. **Work List — Link Style:** Every assignment link in the work list must be rendered as a filled button. The background fill is white (`#FFFFFF`), the text color is brown (`#4A3222`), the corners are perfectly square (`border-radius: 0`), and the inner padding is set to `0.9rem 1.5rem`.
10. **Work List — Hover State:** On hover, the white button background must darkens smoothly (transitioning toward a light, warm gray/off-white roughly 10–15% darker) using a `0.25s ease` CSS transition. The text color and square corners must remain unchanged.
11. **Moving Background:** Implement a low-contrast, continuous drifting-waves background animation. The waves must run at a medium speed (roughly a 12–16 second loop cycle). It must be placed completely behind all text and interactive items (`z-index` layer beneath the main content layout) so it does not distract from readability.
12. **Consistency Rule:** Apply these typography, color, layout, and interaction constraints identically across every future page or structural edit made to this site.
